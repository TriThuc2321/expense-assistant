# Analyze Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `/analyze`, a month/year statistics page with a summary, a category breakdown and a trend chart, linked to filtered transaction lists.

**Architecture:** A Server Component page reads its state from the URL (`view`, `p`, `type`), calls three `userId`-scoped aggregation functions in a new `analytics` service, and passes plain data to two small Recharts client components. The transactions page gains `period=month|year` so every number can link to its rows.

**Tech Stack:** Next.js 16 App Router, React 19, HeroUI v3, Tailwind 4, Drizzle + Postgres, next-intl, Recharts 3, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-11-analyze-design.md`

## Global Constraints

- No AI calls anywhere in this feature.
- Every service function takes `userId` first, filters `transactions.userId = userId` and `transactions.deletedAt IS NULL`.
- "Today" is `todayVn()`; pass `today` into pure functions and services, never call `new Date()` inside them.
- Dates are `YYYY-MM-DD` strings; months are `YYYY-MM`; years in URLs are `YYYY`.
- `p` older than 10 years: any year `< currentYear - 10` falls back to the current period.
- Donut: at most 6 slices. With more than 6 parents, show the top 5 and merge the rest into one "Other" slice (`id: 'other'`). The ranked list below always shows every parent.
- Category colours are token names; render them as `var(--cat-${color})` (see `src/components/ui/category-tile.tsx`). "Other" uses `var(--border-strong)` or the nearest neutral token in `src/app/styles/tokens/colors.css`.
- Money is formatted with `formatVnd` / `Money` (`src/lib/format.ts`, `src/components/ui/money.tsx`).
- Every new string goes in both `messages/vi.json` and `messages/en.json`.
- HeroUI: `.heroui-docs` is not in this checkout. Copy patterns from existing usage (`Tabs`/`TagGroup` in `src/features/transactions/transactions-view.tsx`, `Chip` in `src/features/home/stat-cards.tsx`), and take any new component's API from its `.d.ts` under `node_modules/@heroui/react/dist/components/` (resolve through `node_modules/.pnpm` if needed).
- Next.js: read the relevant guide in `node_modules/next/dist/docs/` before writing routing code (`PageProps`, `loading.tsx`), per `AGENTS.md`.
- Comments only for a non-obvious WHY. oxlint `consistent-type-imports`; only `console.warn/error/info`.
- Conventional Commits. DB tests need Postgres on 5433 (`docker compose up -d --wait`).

## Spec deviations (decided here)

- `parseAnalyzeParams` returns period keys (`p`, `prevP`, `nextP`), not hrefs or labels. Labels are locale-formatted in components, and `analyzeHref()` builds links.
- The spec's `percentChange` is not added: reuse `spentDelta` from `src/features/home/stats.ts`, which already returns `null` when the previous value is 0.
- Settings already links to `/categories` (`src/app/(main)/settings/page.tsx:41`), so no new Settings row is needed.
- The "itself" child row (transactions attached directly to a parent) has no link, because `cat=<parentId>` would also include the children.

## Review Focus

1. **Visiting `/analyze` on the 31st when last month has 30 days**, or on Feb 29. Expect the previous range to end on the last day of the shorter month, not to overflow into the next month. (Task 1)
2. **A transaction dated in the future** (users can pick any date). Expect it not to count in the current month's summary or category totals, which run to today, but the trend axis still shows the whole month. (Task 3)
3. **A user with a single parent category and one child, where all spending is on the child.** Expect `children` to contain just that child, with no "itself" row and no zero rows. (Task 3)
4. **Hand-edited URLs** such as `?view=year&p=2026-08`, `?p=2099-01` or `?p=abc&type=foo`. Expect a valid page for a sensible period, never a 500 error. (Task 2)
5. **`/transactions?period=month&ym=2026-13`.** Expect a fallback to `period=this`, not an empty list or a crash in `monthRange`. (Task 4)

- Produces:

```ts
export type PeriodSummary = {
  income: number;
  expense: number;
  prevIncome: number;
  prevExpense: number;
};
export type CategoryChild = {
  id: string;
  name: string;
  total: number;
  isSelf: boolean;
};
export type CategoryTotal = {
  id: string;
  name: string;
  icon: string;
  color: string;
  total: number;
  children: CategoryChild[];
};

export function periodSummary(
  userId: string,
  range: DateRange,
  prev: DateRange,
): Promise<PeriodSummary>;
export function categoryBreakdown(
  userId: string,
  type: TxType,
  range: DateRange,
): Promise<CategoryTotal[]>;
export function trend(
  userId: string,
  range: DateRange,
  axis: DateRange,
  bucket: TrendBucket,
): Promise<TrendPoint[]>;
```

`categoryBreakdown` runs one query: join `categories` on `transactions.categoryId`, left-join a `parent` alias of `categories` (same pattern as `alias` in `transactions.ts`), and group by the transaction's category. Folding in TypeScript works like this: the parent key is `parentId ?? id`, and the parent's name, icon and colour come from the parent row. Rows whose category is the parent itself become a child with `isSelf: true`, and are kept only if the parent has at least one non-self child. Sort parents and children by total descending, and drop zero totals. `trend` queries `range`, which ends at today for the current period, then calls `fillBuckets` over `axis`. The month key is `to_char(date, 'YYYY-MM')`.
